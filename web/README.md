# web/ , BNB Agent Marketplace site

Next.js 16 (App Router) · React 19 · Tailwind v4 · shadcn/ui (stock, new-york) · lucide-react · motion (via Magic UI) · Geist.


## Run

```bash
pnpm install
pnpm dev                 # http://localhost:3000 , PROBE_LOOP=off skips the 5-minute endpoint probe loop
pnpm build && pnpm start
pnpm lint
```

The shelf data (`app/shelf.json`, `app/shelf-stats.json`) is generated from the ERC-8004 registries at build time and committed; it is not edited by hand.

## Components

`components/ui/*` is generated by the shadcn CLI and is not hand-edited: add or refresh a primitive with
`npx shadcn@latest add <name>` (or a Magic UI registry URL). Domain wrappers that compose them live in `components/*`
(`button`, `tag`, `status-word`, `evidence-word`, `avatar`, `stat`, `pager`, `site-chrome`, …); page-level primitives
in `app/_landing/ui.tsx`.

## Deploy

The site is served at https://bnbagent.trade.
